Setup Firebase Sync
Ikuti 3 langkah berikut untuk sync real-time antar HP:
1
Buka console.firebase.google.com → login Google → Create a project → beri nama (cth: kas-keluarga) → klik Continue sampai selesai
2
Di sidebar kiri klik Realtime Database → Create Database → pilih lokasi → Start in test mode → Enable

Salin Database URL yang muncul (format: https://nama-project-default-rtdb.firebaseio.com)
3
Klik ikon ⚙️ gear di sebelah Project Overview → Project settings → scroll ke bawah ke bagian Your apps

Jika belum ada app: klik ikon </> (Web) → beri nama app → Register app

Setelah ada app, klik Config → salin nilai apiKey dari kode yang muncul
4
Kembali ke app ini → halaman Lainnya → Sinkronisasi Cloud → tempel Database URL dan apiKey → klik Hubungkan

Lakukan langkah yang sama di HP pasangan dengan nilai yang sama persis
🔒 Keamanan: Atur database rules agar hanya bisa diakses dengan URL yang benar. Untuk awal, test mode sudah cukup untuk keluarga.
